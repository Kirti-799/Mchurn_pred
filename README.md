# Mchurn_pred
Customer churn prediction for Myntra-like e-commerce platform
## Results & Conclusion

- Built a churn prediction model for a Myntra-like e-commerce platform.
- Performed complete EDA and preprocessing (missing values, encoding, scaling).
- Trained Logistic Regression as a baseline model.
- Due to class imbalance, accuracy alone was misleading.
- Using class-weighted Logistic Regression improved churn recall from ~53% to ~84%.
- Higher recall helps identify most churn-prone customers, which is critical for business retention strategies.

**Final Model Choice:** Logistic Regression with class balancing.
